# Закрытая панель Super Admin

Адрес панели: `https://tavaar.online/owner/login`.

Этот URL не добавляется в клиентскую навигацию. Все owner procedures проверяют серверную роль `super_admin`; скрытие маршрута само по себе не используется как защита.

## Первоначальное создание владельца

Аккаунт не создаётся автоматически и не добавляется фиктивно. На VPS задайте значения только в защищённой shell-сессии или секретном файле, не коммитьте их:

```bash
cd /root/akdovurak
export OWNER_ADMIN_NAME='Владелец Таваар Доставка'
export OWNER_ADMIN_EMAIL='ваш-email@example.com'
export OWNER_ADMIN_PASSWORD='СильныйПарольСБольшойБуквой1'
pnpm exec tsx scripts/bootstrap-super-admin.ts
unset OWNER_ADMIN_NAME OWNER_ADMIN_EMAIL OWNER_ADMIN_PASSWORD
```

Команда использует тот же scrypt-формат, что и существующая email-аутентификация, помечает email подтверждённым только потому, что создание выполняется владельцем на сервере, и отказывается повышать уже существующий аккаунт. Повторный запуск с тем же email также останавливается без изменений.

## Возможности текущей версии

Панель показывает реальные числа пользователей, заведений, заказов, заявок и оборот в копейках; содержит списки пользователей, заказов, заведений и журнал аудита; позволяет одобрять или отклонять заявки заведений. Одобрение записывается в аудит и сохраняет действующую атомарную логику создания заведения и membership.

Пока отдельно не реализованы mutating screens для блокировки пользователей, промокодов, комиссий, финансовых экспортов, MFA и управления сотрудниками. Эти функции не маскируются как готовые: их серверные процедуры и UI нужно добавлять отдельными этапами.
